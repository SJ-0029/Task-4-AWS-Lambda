# Task-4-AWS-Lambda
# ☁️ Task 4: Deploy a Serverless Function (AWS Lambda)

## 🎯 Objective
To understand serverless computing by creating and deploying a simple AWS Lambda function that runs automatically when triggered, without managing any servers.

---

## 🧭 Steps Performed
1. Created a new AWS Lambda function (`MyFirstLambdaFunction`).
2. Used Python 3.9 runtime and AWS basic execution role.
3. Deployed a simple function returning a greeting message.
4. Configured API Gateway to trigger Lambda via HTTP.
5. Tested using browser and Postman.
6. Verified output: **"Hello from my first AWS Lambda function!"**
